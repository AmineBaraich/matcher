# CV Job Matcher

CV Job Matcher is an application that analyzes your CV and finds relevant job opportunities based on your skills and experience.

## Features

- CV Analysis
- Job Recommendations
- Market Insights
- Job Opportunities

## Setup

1. Install requirements
```bash
pip install -r requirements.txt
```

2. Run the application
```bash
python app.py
```

## Usage

Upload your CV (PDF format) and enter your Gemini API Key to get started. You can also specify your location.
